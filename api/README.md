# Public API snapshots

Generated by `scripts/api-snapshots.py`; **do not edit by hand**. One file per
published crate and feature set, listing every public item, one per line.
A pull request that changes the public API changes these files, so the change
is in the diff.

After changing public API, run:

```sh
python3 scripts/api-snapshots.py update
```

CONTRIBUTING.md, "API snapshots", has the details (the tools it needs, what the
CI job does, how this relates to the Semver checks job).

| File | Feature set |
|---|---|
| `<crate>/default.txt` | the crate's default features |
| `<crate>/no-default-features.txt` | `--no-default-features` (for `ponko`: headless, no window) |
| `<crate>/docs-rs.txt` | the features docs.rs builds: everything public |
| `ponko/3d.txt` | the defaults plus `3d` |

A set that lists the same API as `default` has no file (a missing
`no-default-features.txt` means the crate has the same API without its default
features). If it starts to differ, its file appears in the diff.
