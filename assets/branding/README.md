# Ponko logo

The Ponko red panda. `ponko-face.svg` is the master.

| File | Use |
|---|---|
| `ponko-face.svg` | The logo, transparent. Use it wherever SVG works (web, README, docs). |
| `ponko-face-1024.png`, `-512.png`, `-256.png` | Square PNGs, transparent: social previews, avatars, app icons. |
| `favicon.svg`, `favicon.png`, `favicon.ico` | Browser tab icon (SVG, 32 px PNG, and 16/32/48 px in one `.ico`). |
| `apple-touch-icon.png` | 180 px on a solid background, for iOS home screens. |

Colors: orange `#D4532A`, cream `#F6E7D6`, dark brown `#2A1916`.

## Using the logo

The repository doesn't yet say under which terms the logo may be used outside
the project. Until it does, ask in an issue or discussion first. The logo is
not part of the published `ponko` crate.
