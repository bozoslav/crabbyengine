### Asset handle inventory (first stage of #161)
- Add `Ctx::asset_inventory()`: live handles by `AssetClass` (textures,
  render targets, texture arrays, materials, shaders, meshes, GPU buffers,
  effects, compute passes, sounds) with estimated bytes, counted from the
  same tables that decide whether a handle is live, so it works headless.
  Windowed games add `GpuResidency`: what the renderer actually holds.
- `AssetInventory::growth_since(&baseline)` names the classes that grew,
  for leak tests. The control endpoint's `perf.get` answer gains `assets`.
