### Shader diagnostics (first stage of #153)
- Add `Ctx::shader_status`: the latest compile or hot reload result of each
  game shader (material shaders, screen effects, compute passes) as
  `ShaderStatus` / `ShaderOutcome`, with a reload count and frame.
- Add `ShaderDiagnostic`: shader name, kind, active variant, line and column
  mapped back from the composed shader to the game's own WGSL (or flagged as
  in the engine's code around it), cause, label and source line. Shader
  error messages now use these lines instead of the composed shader's.
- On native, material shader pipelines are built in a validation error
  scope: a reload the GPU rejects keeps the last good pipelines instead of
  breaking the device.
- Add the `shaders.status` control method and the `shader_status` MCP tool
  returning the same results.
